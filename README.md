# 🌟 AI-Powered Placement & Skill Gap Analyzer  
### Full Stack Project — Node.js + Express + MongoDB + FastAPI + Pure CSS Glossy UI

This project is a **complete production-ready AI Placement Platform** built with:

- **Frontend:** HTML + Pure CSS (Apple-style glossy pastel UI)
- **Backend:** Node.js + Express + MongoDB + JWT
- **NLP Microservice:** Python FastAPI + BERT + spaCy
- **AI Features:**
  - Resume Parsing
  - Skill Extraction
  - Job Role Matching
  - ATS Score
  - Readiness Score
  - Skill Gap Analysis

# 🚀 SETUP GUIDE

## 🔧 1. Install Backend
```
cd backend
npm install
```

Run server:
```
node server.js
```

---

## 🧠 2. Install NLP Microservice
```
cd nlp-service
pip install -r requirements.txt
```

Run NLP server:
```
uvicorn main:app --reload --port 5001
```

---

## 🌐 3. Open Frontend
Simply open:
```
frontend/index.html
```
